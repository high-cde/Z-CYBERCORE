# Z-CYBERCORE Wiki

Z-CYBERCORE raccoglie le componenti di security operations dell'ecosistema ZDOS. La piattaforma privilegia osservabilità, qualità delle evidenze, policy e automazione controllata; non è un framework per attacchi autonomi.
