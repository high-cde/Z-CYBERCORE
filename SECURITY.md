# Policy di sicurezza

## Ambito

Z-CYBERCORE è orientato a security operations controllate. Non usare il repository per attività verso sistemi privi di autorizzazione esplicita. La policy operativa, inclusi confini e capability escluse, è descritta in [SECOPS-STATUS.md](SECOPS-STATUS.md).

## Segnalazione responsabile

Non aprire issue pubbliche per vulnerabilità, segreti, dati personali, endpoint sensibili o dettagli che rendano un abuso immediatamente riproducibile. Usare una segnalazione privata ai manutentori del repository tramite GitHub Security Advisories; se non disponibile, contattare l'organizzazione proprietaria su GitHub senza pubblicare dettagli tecnici.

Una segnalazione utile include commit interessato, impatto, passaggi minimi riproducibili, prerequisiti e suggerimenti di mitigazione. I manutentori confermeranno la ricezione, valuteranno il problema e coordineranno una divulgazione responsabile.

## Fuori ambito

Sono fuori ambito segnalazioni basate su asset non autorizzati, interruzioni intenzionali del servizio, ingegneria sociale, scansioni aggressive e richieste di funzionalità offensive.
